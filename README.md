NFORME APP — Excel

Projeto desenvolvido em Excel para organizar informações pessoais, rendimentos bancários e entradas mensais de receita em uma interface simples, visual e navegável.

Projeto criado para fins de estudo, prática de Excel e portfólio profissional. Os dados apresentados são fictícios.

📌 Objetivo

O INFORME APP foi pensado como uma pequena aplicação em Excel para centralizar informações que podem ser utilizadas na organização e conferência de documentos e dados financeiros.

🧩 Módulos

1. Dados do Titular

Cadastro de informações como:

Nome

CPF

Data de nascimento

Título de eleitor

Cônjuge

Endereço

CEP

Telefone e celular

E-mail

Informações sobre alterações da entrega anterior

Dependente cônjuge

Residência no exterior

2. Informes de Rendimentos Bancários

Permite registrar:

Banco

Valor atual

Nome do arquivo/documento de apoio

O valor total é calculado automaticamente.

3. Notas Bancárias e Extratos de Holerites

Tabela para registrar entradas mês a mês:

Data

Categoria

Valor

Holerite

Recursos:

Lista de categorias;

Formatação monetária;

Filtros;

Tabela estruturada do Excel;

Total automático das entradas.

🛠️ Recursos utilizados

Microsoft Excel

Fórmulas

Validação de dados

Tabelas estruturadas

Hiperlinks para navegação entre abas

Formatação de datas e valores monetários

Organização visual de uma interface de aplicativo
